# KitchenPulse AI

## รันบนเครื่องกรรมการแบบออฟไลน์

ต้องติดตั้ง Node.js 18 ขึ้นไปก่อน จากนั้นเปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วรัน:

```bash
npm start
```

เปิดเว็บที่:

```text
http://localhost:3000
```

ระบบอ่านและบันทึกออเดอร์ผ่าน `server.js` และเก็บข้อมูลถาวรไว้ที่ `data/mock-orders.json` ดังนั้นเมื่อรีเฟรชหน้าหรือปิดแล้วเปิดใหม่ ข้อมูลจะยังอยู่

## แชร์ให้กรรมการเปิดจากเครื่องอื่นในเครือข่ายเดียวกัน

1. รัน `npm start`
2. หา IP ของเครื่องที่รันเซิร์ฟเวอร์ เช่น `192.168.1.20`
3. ให้กรรมการเปิด:

```text
http://192.168.1.20:3000
```

4. อนุญาต Node.js ผ่าน Firewall หากระบบถาม

หากกรรมการอยู่นอกเครือข่ายเดียวกัน ให้ใช้ตัวเลือก deployment ด้านล่างแทน

## Deploy ขึ้น Render

1. Push โปรเจกต์ขึ้น GitHub
2. สร้าง Web Service ใหม่บน Render
3. เลือก Repository นี้
4. ตั้งค่า:
   - Build Command: `npm install`
   - Start Command: `npm start`
5. Deploy แล้วส่ง URL ให้กรรมการ

หมายเหตุ: Render แบบ Free อาจหยุดพักเมื่อไม่มีการใช้งาน และไฟล์ JSON บนบริการบางประเภทอาจไม่เหมาะกับข้อมูลถาวรระยะยาว แต่เหมาะสำหรับเดโม

## Deploy ขึ้น Railway

1. Push โปรเจกต์ขึ้น GitHub
2. สร้าง Project ใหม่บน Railway
3. Deploy จาก GitHub Repository
4. Railway จะใช้ `npm start`
5. สร้าง Public Domain แล้วส่ง URL ให้กรรมการ

## สิ่งที่ควรตรวจสอบก่อนส่ง

- เปิดเว็บจาก `http://localhost:3000` หรือ URL deploy ไม่ใช่การดับเบิลคลิกไฟล์ HTML
- ทดสอบเพิ่มออเดอร์ แล้วรีเฟรชว่าข้อมูลยังอยู่
- ทดสอบปุ่ม AI QC Check และหน้า `qc.html`
- เตรียมบัญชีหรือ URL สำรอง หาก AI API ภายนอกใช้งานไม่ได้
- อย่าใส่ secret หรือรหัสผ่านจริงใน repository สาธารณะ
