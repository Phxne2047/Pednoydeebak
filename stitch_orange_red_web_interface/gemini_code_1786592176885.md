# KitchenPulse AI — Google Stitch Design Prompts

ชุด Prompts สำหรับคัดลอกไปใช้ใน Google Stitch เพื่อออกแบบ UI และ Design System ของระบบ **KitchenPulse AI** โดยเรียงตาม Master Flow ทั้ง 5 หน้าจอ

---

## 🎨 Master Theme & Style Guide
- **Concept:** Enterprise-grade Smart Kitchen Operating System (AI Operations Co-Pilot)
- **Color Palette:** Dark Slate background (`#0F172A`), Emerald Green for Pass/Normal (`#10B981`), High-Contrast Alert Accents (Red `#EF4444` for Bottleneck/Fail, Yellow `#F59E0B` for Warning)
- **Typography & UI:** Clean, readable typography, high-contrast badges, cards with soft borders, compact layout for fast-paced operational workflows.

---

## 📌 Screen 1: Master Theme & System Layout
> **Medium:** Web Application  
> **Prompt:**  
> "A modern SaaS Web Dashboard layout for 'KitchenPulse AI', a smart kitchen management platform. Clean UI, dark slate/emerald color palette with high-contrast alert accents (red for severe bottleneck, yellow for warning, emerald green for pass/normal).  
> **Layout Features:**  
> - Top Navigation Header with 'KitchenPulse AI' branding, live system time, 'System Normal' indicator badge, and a Role Switcher toggle (Manager / Kitchen Staff).  
> - Left Sidebar Menu with icons: 1. Live Kitchen Board (Active), 2. Bottleneck & Queue Optimizer, 3. AI QC Gate Guard, 4. Daily Analytics, 5. Settings.  
> The overall design should feel like an enterprise-grade, fast-paced restaurant operation OS."

---

## 📌 Screen 2: Live Kitchen Board (Kanban Main Screen)
> **Medium:** Web Application  
> **Prompt:**  
> "A real-time Kanban Order Board for restaurant kitchen staff.  
> **Top Banner:** Summary metrics cards showing Total Orders: 8, In Progress: 4, Ready for QC: 2, Served: 2.  
> **Kanban Board Layout (4 Columns):**  
> 1. 'New Orders'  
> 2. 'Cooking' (showing station tags like [Stir-Fry], [Boil], [Fry])  
> 3. 'Ready for QC' (featuring a prominent primary action button: '🔍 AI QC Check')  
> 4. 'Completed'  
> **Order Card Design:** Includes Table Number (e.g., Table 3 - #008), dish names, SLA Countdown Timer (progress bar changing green to red), and a highlighted yellow box for Special Requests (e.g., 'No Cilantro, Extra Fried Egg'). Design should be highly readable for high-stress kitchen environments."

---

## 📌 Screen 3: Bottleneck & Queue Optimizer
> **Medium:** Web Application  
> **Prompt:**  
> "A kitchen station load monitoring and AI queue optimization dashboard.  
> **Top Section - Station Health Heatmap (Horizontal Cards):**  
> - 'Stir-Fry Station': Red Alert Badge 'OVERLOAD' (5 orders pending, 12 min delay risk).  
> - 'Boil Station': Green Badge 'NORMAL' (1 order pending).  
> - 'Deep-Fry Station': Yellow Badge 'MODERATE' (2 orders pending).  
> **Middle Section - AI Insight Box:** A highlighted container with an AI icon displaying text: 'Warning: Stir-Fry Station is overloaded due to concurrent Basil Pork orders. Suggested action: Batch-cook base ingredients for Tables 3, 5, and 8.'  
> **Primary CTA Button:** A large gradient action button '🚀 Run AI Queue Optimizer'.  
> **Bottom Section:** A side-by-side comparison list showing 'Current Queue vs AI Optimized Queue'."

---

## 📌 Screen 4: AI QC Gate Guard (TrustPlate Vision Check)
> **Medium:** Web Application / Modal View  
> **Prompt:**  
> "A visual AI Food Quality Control (TrustPlate AI) inspection panel for a restaurant kitchen.  
> **Left Panel - Order Verification:** Displaying Table 3 - Basil Pork Rice. Checklist items: [x] No Cilantro (Strict Control), [x] Extra Fried Egg.  
> **Center Panel - Camera Upload Area:** A clean dropzone with preview image of a Basil Pork dish, featuring an 'Upload / Take Photo' icon button.  
> **Right Panel - AI Inspection Results:**  
> - Large Status Badge: Red 'FAIL / WARNING' (Detected cilantro on dish).  
> - AI Analysis Summary: 'Detected garnish cilantro contradicting the special request. Fried egg is present.'  
> - Action Buttons: Disabled 'Serve' button, Enabled '🔄 Return to Kitchen for Fix' button."

---

## 📌 Screen 5: Daily Analytics & Business Impact
> **Medium:** Web Application  
> **Prompt:**  
> "A modern executive analytics dashboard showing kitchen operational impact.  
> **Top Metric Cards:**  
> 1. Avg. Kitchen Prep Time: 11.5 mins (28% speed improvement badge).  
> 2. Wrong Order Rate: 0% (14 dish errors prevented today).  
> 3. Estimated Savings: ฿4,500/month in wasted food.  
> **Main Visuals:**  
> - Line chart comparing 'Cooking Speed Before vs After KitchenPulse AI'.  
> - Donut chart showing 'Blocked Special Request Errors by Type' (e.g., No Spicy, No Cilantro, Peanut Allergy).  
> Minimalist, clean data visualization style suitable for pitching to restaurant owners."
